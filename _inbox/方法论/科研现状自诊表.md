## 5. 写作

- 当前在写作 9 步的哪一步（画 pipeline 草图 / 列 ablation / 写 method / 改 intro / 写 experiment / Review / 取名 / 反复改）？
- 论文逻辑骨架锁了吗？自洽四检查能过吗：
  - Limitations → Key Idea：解法对得上问题吗？
  - Key Idea → Challenges：挑战是从 idea 自然长出来的吗？
  - Challenges → Methodology：每个模块解一个挑战吗？
  - Methodology → Contributions：贡献指向具体章节吗？
- 做过 self-review 吗（5 大类拒稿因素）？
- 中文正文去过 AI 味吗（禁机械连接词 / 空壳强调 / 翻译腔）？
